# Код-стайл

## Общие правила

- Используй PHP 8.1+ и `declare(strict_types=1);` в PHP-файлах.
- Сохраняй кодировку UTF-8.
- Используй CRLF, 4 пробела для отступов и максимальную длину строки 120 символов согласно `.editorconfig`.
- Не форматируй файл целиком, если задача касается небольшого участка кода.

## PHP

- Пространство имен основного кода: `DraculAid\PhpTools\`.
- Пространство имен тестов: `DraculAid\PhpTools\tests\`.
- Классы и варианты перечислений называй в `PascalCase`.
- Методы, свойства, параметры и локальные переменные называй в `camelCase`.
- Константы называй в `UPPER_SNAKE_CASE`.
- Явно указывай типы параметров и возвращаемых значений, когда это возможно.
- Предпочитай строгие сравнения `===` и `!==`.
- Для новой функциональности сохраняй совместимость с PHP 8.1.

## Структура файлов

- Основной код размещай в `src/` в каталоге, соответствующем namespace.
- Тесты размещай в `tests/` в каталоге, соответствующем тестируемой области.
- В начале PHP-файлов сохраняй существующий формат заголовка проекта, если он уже используется в аналогичных файлах.

## PHPDoc и комментарии

- Для всех элементов классов (даже не публичных) добавляй PHPDoc.
- В PHPDoc нужно использовать русскоязычные описания.
- Не добавляй комментарии, которые просто повторяют код.

## Оформление кода

- Добавляй фигурные скобки всегда с новой строки
- PHP никогда не импортируй, а пиши с полным именем, например \DateTime

## Оглавления классов

- Во всех новых классах добавляй оглавление в PHPDoc класса: после краткого описания класса и перед тегами `@see`,
  `@since` и другими PHPDoc-тегами.
- При добавлении в существующий класс публичного метода, константы, свойства или варианта перечисления добавляй этот
  элемент в оглавление. Оглавление должно содержать все публичные элементы класса.
- Начинай оглавление строкой `Оглавление:`.
- Если элементов много, объединяй их по назначению в разделы. Заголовок раздела оформляй как
  `<br>--- Название раздела`.
- Каждый элемент оформляй отдельной строкой:
  `<br>- {@see ссылка_на_элемент} - Краткое описание`.
- В ссылках на статические элементы используй имя класса, а на нестатические — `self`:
    - статический метод: `ClassName::method()`;
    - нестатический метод: `self::method()`;
    - статическое свойство: `ClassName::$property`;
    - нестатическое свойство: `self::$property`;
    - константа или вариант перечисления: `ClassName::ELEMENT`.
- Описание элемента пиши на русском языке, кратко передавая его назначение.

Пример оглавления
```php
/**
 * Тестовый класс
 * 
 * Оглавление:
 * <br>--- Константы
 * <br>- {@see TestClass::FIRST} - Первое значение
 * <br>- {@see TestClass::SECOND} - Второе значение
 * <br>--- Создание объекта
 * <br>- {@see TestClass::createBase()} - Создает пустой объект
 * <br>- {@see TestClass::createInt()} - Создает объект, который хранит число
 * <br>--- Свойства
 * <br>- {@see self::$valInt} - Значение-число
 * <br>- {@see self::$valString} - Значение-строка
 * <br>--- Установка значений
 * <br>- {@see self::setFirst()} - Установит строковое значение как Первое
 * <br>- {@see self::setSecond()} - Установит строковое значение как Второе
 * <br>--- Прочие функции
 * <br>- {@see self::clear()} - Очистит значения
 */
class TestClass {}
```
